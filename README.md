# CourtFlow

篮球比赛登记工具，提供两个独立入口：

| 系统 | 在线入口 | 用途 |
| --- | --- | --- |
| **CourtFlow Pro V4.2** | [打开 Pro](https://yyysheng.github.io/basketballrecord/pro/) | 表格式实时技术统计、事件纠错和赛后报表 |
| CourtFlow Lite v0.3 | [打开 Lite](https://yyysheng.github.io/basketballrecord/lite/) | 轻量比赛记录及比赛记录表 PDF |

根网址自动跳转 Pro。GitHub Pages 使用 `basketballrecord` 分支的根目录。两个系统独立运行，比赛数据不共用。

## Pro V4.2 使用说明

### 1. 赛前设置

1. 打开 Pro，填写主队、客队名称。
2. 编辑球员名单和球衣号码，姓名可选。号码必填，同队不可重复。
3. 为两队选择球衣颜色：赤、橙、黄、绿、青、蓝、紫、白、黑。
4. 每队勾选恰好 5 名首发，点击「确认首发并开始比赛」。

建议电脑、手机和平板使用横屏。视口为竖屏比例时会显示「请使用横屏布局或扩大浏览器宽度」提示。表格支持横向及纵向滚动，号码与姓名列便于辨认球员。

### 2. 点击格子登记统计

主队与客队上下排列，每队只显示当前场上 5 人。主表不显示个人累计得分，顶部总比分从有效投篮事件自动计算。页面没有比赛计时器。

| 项目 | 每人操作格数 | 操作循环 |
| --- | --- | --- |
| 两分、三分 | 各 4 格 | 空白 → √ 命中 → × 未中 → 空白撤销 |
| 罚球 | 2 格 | 同投篮循环，命中计 1 分 |
| 进攻篮板、防守篮板 | 各 3 格 | √ 登记 → × 撤销 → √ 恢复 |
| 助攻、抢断、盖帽、失误、普通犯规、其他犯规、违例 | 各 1 格 | 同非投篮循环；其他犯规首次需选择类别 |

- 两分、三分、罚球命中分别计 2、3、1 分。改为未中时撤回得分和命中，保留出手；再次撤销时撤回该次出手。
- **同一格最后一次操作后的 3 秒内**，再次点击是在修改同一事件，非投篮格不会因此新增另一条独立事件。
- **3 秒后只隐藏临时标记及反馈，累计数据保留。**之后再点击同一格会新增事件，旧记录不会被覆盖。
- 按钮内球衣号码水印持续显示；左侧的 `+2`、`+MISS`、`−1` 等浮动文字表示本次操作反馈。
- 违例、失误、犯规、投篮与罚球分别由记录员登记，软件不自动关联。

### 3. 节次、换人与犯规

- **下一节**：更新节次，保留全部累计统计。
- **换人**：选择球队、一名场上球员和一名替补后确认。下场球员的统计继续保留。
- **普通犯规**：直接登记普通个人犯规。
- **其他犯规**：先选择 T1（第一类技术犯规）、T2（第二类技术犯规）、DI（破坏性犯规）、FL（恶意犯规）或 D（直接取消比赛资格犯规）。取消菜单不建事件；3 秒内再次点击该格撤销或恢复原事件。改变类别需使用事件编辑。
- **替补席犯规**：选择球队、责任主体和类别，区分替补球员、教练、随队人员；非球员责任人可填写姓名。

犯规类别以现场裁判报告为准。软件记录类别与责任主体，不自动安排罚球、分配球权或执行取消比赛资格。旧记录中的 U 不自动转换为 DI 或 FL，应人工核实。

### 4. 查看与修正事件

宽屏右侧显示事件记录；空间不足时点击顶部「待更正」打开抽屉，可筛选「全部事件」或「待处理」。

- **稍后处理**：为事件加红框并增加待处理计数，不改变得分和统计；核实后点击「标记已解决」。
- **定位**：对支持定位的事件查找相应球员和项目。
- **编辑**：更正球员、事件类型及有效状态，累计统计与比分同步更新。
- **作废 / 恢复**：更改事件是否有效，原记录保留。
- **轨迹**：查看事件 ID、创建时间和修改历史。事件时间是实际操作时间，不是比赛剩余时间。
- **撤销**：撤回最近一次可撤销操作，包括对既有事件的更改。

页面下方的数据工具提供「历史与纠错」「累计统计」、JSON 导入导出及球员 CSV。

### 5. 结束比赛与赛后统计

1. 点击「结束比赛」并确认，进入专用赛后统计页。
2. 查看最终比分、全体报名球员及球队合计，包括两分、三分、总投篮、罚球的命中 / 出手和命中率。
3. 如仍有待处理事件，报表会提示核实。需要修订时点击「恢复记录」并确认，再继续登记或纠错。

完赛后统计登记、换人、节次切换和历史数据修改进入只读状态，恢复记录后可继续操作。总投篮为两分与三分之和，不含罚球；命中率按命中数除以出手数计算，未出手显示「—」。

| 导出操作 | 内容 |
| --- | --- |
| Excel `.xlsx` | 球员统计、全部事件、比赛信息三个工作表 |
| 球员 CSV | 全体报名球员及球队合计，包含命中率 |
| 事件 CSV | 序号、节次、球员、状态、犯规类别、待核对标记等 |
| 完整 JSON 备份 | 可供导入恢复的完整比赛数据 |
| 打印 / 保存 PDF | 调用浏览器打印，选择打印机或「另存为 PDF」 |

### 6. 开启新比赛与历史比赛

完赛后点击「开启新比赛」，再确认「保存历史并开启新比赛」：当前比赛归档到本机，随后返回新比赛的赛前设置。新比赛不会继承原比分和统计。

赛前设置中的「历史比赛」可查看已归档赛果、打开报表或下载该场 JSON。历史归档保存在当前浏览器，建议每场结束后额外下载完整 JSON 备份。

### 7. 本地保存、备份与恢复

- 当前 Pro 的存储键为 `courtflow-pro-table-v1`，历史归档键为 `courtflow-pro-table-v1-archives`。
- 刷新同一浏览器、同一网站地址可恢复已保存比赛。更换设备、浏览器、浏览器配置文件或网站来源不会自动带入存档。
- 使用「导出 JSON」或「完整 JSON 备份」下载比赛，在比赛页使用「导入 JSON」恢复匹配格式的备份。**导入会替换当前 Pro 比赛，导入前请先备份当前比赛。**
- 清除网站数据或浏览器存储可能删除当前比赛与归档。本项目没有云端保存或多设备自动同步。
- 新表格式 Pro、旧球权版 Pro 和 Lite 使用独立存储键。旧球权版 JSON 不应作为新版表格式比赛备份直接导入。
