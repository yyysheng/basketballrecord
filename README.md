# CourtFlow 篮球比赛记录系统｜简易使用说明

CourtFlow 提供两套独立的篮球比赛记录系统，分别用于完整技术统计和 FIBA 比赛记录表登记。

## 一、CourtFlow Pro｜完整技术统计版

**访问地址：** https://yyysheng.github.io/basketballrecord/pro/

**适用场景：** 需要记录球员得分、投篮命中率、篮板、助攻、抢断、失误、盖帽和犯规等完整技术数据的比赛。

### 1. 赛前准备

点击顶部「🏀 球队与阵容」，设置双方队名、球员号码、姓名、球衣颜色及首发五人。

通过「设置」调整比赛节数、每节时间、加时长度及自动计时模式。

### 2. 开始比赛与球权操作

- 第一节开始，点击实际首次控制篮球的球员，系统自动确定初始交替球权箭头。
- 点击当前持球人的同队队友，自动记录一次传球。
- 点击对方球员，自动记录当前持球人的失误及对方球员的抢断。
- 得分、失误、篮板等事件会更新球权状态，按页面提示继续操作。

### 3. 投篮及得分

确认球场上的当前持球人后，点击左侧对应按钮：

- 「两分命中 / 三分命中」：记录得分，再选择是否有助攻和犯规。
- 「两分不中 / 三分不中」：确认是否存在投篮犯规；无犯规时继续登记盖帽、篮板或出界。
- 罚球通过犯规登记流程进入，逐次选择命中或未中。

注意：进球一旦登记，关闭后续助攻、犯规弹窗并不会自动撤销得分。记错时请使用「撤销」或历史事件编辑。

### 4. 犯规、暂停与换人

右侧「比赛 · 事件」区域可登记防守犯规、其他犯规、出界、违例、争球、球队暂停及换人。

犯规按提示选择球员、类型及罚球次数。

换人时选择下场和上场球员，确认后系统更新场上阵容。

### 5. 纠错与导出

- 「撤销」：撤回最近登记的事件。
- 「事件」：编辑、插入或删除历史记录。
- 「待办」：处理暂时无法确认的事件。
- 「导出」：下载完整 JSON 备份、事件 CSV 或技术统计 CSV。

**最终输出：篮球比赛完整技术统计数据及事件记录。**

## 二、CourtFlow Lite｜FIBA 记录表版

**访问地址：** https://yyysheng.github.io/basketballrecord/lite/

**适用场景：** 需要快速登记比赛得分、个人犯规、球队暂停、换人，并生成 FIBA 格式比赛记录表的比赛。

### 1. 赛前信息登记

进入「赛前准备」，填写赛事名称、比赛日期、地点、双方队名、球员号码及姓名。

选择双方首发五人，填写队长、教练和赛事工作人员等信息。

确认完成后进入「比赛记录」。

### 2. 比赛计时

比赛界面上方显示当前比分、节次和倒计时。

- 「▶ 继续」：开始或恢复倒计时。
- 「Ⅱ 暂停」：停止倒计时。
- 「校时」：手动修正剩余时间。
- 「下一节」：结束当前节次，进入下一节或加时。

本系统不记录24秒进攻计时。

### 3. 球员得分与犯规登记

双方当前场上球员左右排列。

点击球员号码，进入登记窗口，同时显示：

**得分登记：** 点击 `+1 / +2 / +3`，确认后计入该球员和所属球队的得分。

**犯规登记：** 选择犯规类型、裁判判罚的罚球次数，再确认登记。

两项操作彼此独立。例如出现2+1：

先给得分球员登记2分，再给犯规球员登记犯规。如果加罚命中，给罚球球员登记1分即可。

所有操作都提供取消方式，已经提交的错误记录可通过撤销或历史编辑处理。

### 4. 换人

点击球员列表上方的独立「⇄ 换人」按钮。

页面切换为四列：

`A场上 | A替补 | B场上 | B替补`

先选择下场球员，再选择同队上场球员。

支持双方多组换人同时登记。点击「确认换人」后，系统自动更新场上球员列表；也可以取消整批操作。

### 5. 暂停登记

双方暂停记录位于比赛界面顶部。

点击对应球队「+ 登记暂停」，确认后自动记录使用次数，并更新暂停格。

系统区分上半场、下半场和加时的暂停额度。

### 6. 实时记录表与 PDF 导出

比赛界面常驻显示 FIBA 格式记录表。

每次登记得分、犯规、暂停或换人后，记录表自动更新，无需手动刷新。

记录表支持适应宽度、70%、85%、100%缩放。

点击「导出 PDF」，在浏览器打印窗口选择：

- 纸张：A3
- 方向：纵向
- 缩放：100%
- 关闭页眉页脚
- 目标打印机：另存为 PDF

保存后即可获得比赛记录表 PDF。

**最终输出：参照 FIBA 2026 规则制作的篮球比赛记录表 PDF。**

## 三、两套系统共同注意事项

1. Pro 与 Lite 是两套独立系统，比赛记录不会自动互通。
2. 比赛数据主要保存在当前设备的浏览器本地，建议每场比赛后及时导出 JSON 备份。
3. 记录员应根据现场裁判判罚进行登记，系统不会代替裁判作出比赛判决。
4. Lite 的 FIBA PDF 功能仍处于测试阶段，正式赛事使用前应核对记录内容和赛事要求。
5. 如遇到误操作，优先使用取消、撤销或历史编辑，不建议直接清空全部比赛数据。

**选择建议：**

需要完整技术分析，使用 **Pro**。

需要快速记分、犯规登记及 FIBA 记录表，使用 **Lite**。
