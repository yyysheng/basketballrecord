# CourtFlow Lite v0.3 使用指南

[在线使用](https://yyysheng.github.io/basketballrecord/lite/) · [源码](../lite/index.html) · [返回项目首页](../README.md)

Lite 是独立的比赛记录表系统，围绕现场计分和 FIBA 2026 式样记录表工作，不提供 Pro 的完整篮板、助攻等技术统计。当前记录表及 A3 PDF 为实验性输出，正式使用前应核对，签字由现场负责人完成。

## 赛前设置

1. 在「赛前准备」填写赛事名称、场次、日期、时间、地点及裁判、记录员、计时员等信息。24 秒计时员字段只用于表头。
2. 编辑 A / B 队名称、主教练、第一助教和九色球衣配色。
3. 每队登记 5–12 人，填写号码，可填写姓名、队长，勾选恰好 5 名首发。号码可使用 `00`，同队不能重复。
4. 点击「确认名单 · 进入比赛」。已有记录时该按钮用于返回比赛记录。比赛开始后不能随意移除报名球员。

「载入完整示例比赛」会经过确认并覆盖当前比赛，只适合试用；有重要数据时应先导出备份。「清空 / 重新开始」也会清除当前比赛，应谨慎确认。

## 实时计分与计时

比赛页显示双方比分、场上球员、个人得分及犯规、球队犯规、暂停使用情况和实时记录表。点击球员号码，选择 1 / 2 / 3 分并确认，得分记录进入事件历史并更新逐分栏。

倒计时通过暂停 / 继续按钮手动控制，可以调整时间；切换下一节需确认，常规节为 10 分钟，加时为 5 分钟。页面不模拟跳球。实际操作时间与比赛计时由记录员核对。

## 犯规、暂停与换人

- 点击球员，在犯规操作中选择 P、DI、FL、T1、T2 或 D，核对罚球数及取消标记后确认。类别以裁判报告为准。球员达到 5 次犯规时会提示按裁判指示换人。
- 教练 / 替补席入口区分 C、B、BD、D 等记录类别，核对责任归属后登记。
- 点击球队的「登记暂停」并确认。界面区分上半场 2 次、下半场 3 次和加时暂停，第四节最后 2 分钟的限制需结合现场判罚核实。
- 点击「换人」，先选择场上球员，再选择同队替补，可登记双方多组换人后确认。取消不会提交未确认的换人。原球员的得分、犯规和参赛记录保留。

## 历史纠错

通过事件记录查看计分、犯规、暂停、换人和节次事件，可编辑或删除事件，并使用撤销入口撤销最近事件。修改后页面重新投影比分及记录表。应对照现场纸面记录核实节次、剩余时间及球员，不把示例比赛当作真实赛事。

## FIBA 记录表预览

桌面比赛页右侧显示实时记录表；窄屏中记录表位于比赛记录区域下方。每次登记会更新球队名单、犯规、暂停、逐分记录及各节比分。可选择适应宽度、70%、85% 或 100% 缩放查看。

记录表依据 FIBA 2026 附录 B 式样实现，当前输出不是已经裁判签署的正式记录。底部仍可能包含旧模板 v0.2 的历史字样，应用标题及当前发布版本为 v0.3。

## PDF 保存与备用打印

1. 点击记录表旁「下载 / 分享 PDF」。v0.3 在本机生成 A3 图像型 PDF，无需上传比赛数据。
2. 在支持文件分享的 iPhone / iPad 上，通过系统分享菜单存入「文件」或其他目标；其他浏览器通常直接下载，请检查下载列表。
3. 如果直接 PDF 生成失败，可点「备用打印」，在浏览器打印界面选择打印机或「另存为 PDF」，检查纸张方向、缩放及预览后保存。备用打印使用原 HTML 记录表模板，与直接下载的 A3 图像型 PDF 路径不同。
4. 输出前检查球员、逐分、犯规、暂停、各节及最终比分。正式记录的签字需另行完成。

当前模板逐分栏最多容纳每队 160 分；任一队超出时会阻止无损单页导出。超过三个加时也有单页暂停栏限制。遇到限制应先保存 JSON，不应把不完整记录表作为完整输出。

## 本地存档与备份

Lite 使用独立键 `courtflow-lite-v01` 保存当前比赛，刷新后读取；不与 Pro 的比赛和归档共用。页面重新载入时计时器保持暂停，应核对时间后继续。

顶部「导出备份」下载 JSON；「导入备份」用于恢复 Lite 备份。导入前先导出当前比赛，因为恢复可能替换当前记录。Pro JSON 与 Lite JSON 格式不同，不能互相导入。

数据默认仅存当前浏览器及网站来源。清理网站数据、使用隐私模式或更换设备可能造成存档不可用，不提供云端自动同步。重要比赛同时保存 JSON 和已核对的 PDF。下载后本地打开的页面与 GitHub Pages 网站也不共享浏览器存储。
